# Code of conduct / Davranış kuralları

## English

Claude Pro Dev welcomes people of every background and experience level. These rules apply to repository issues, pull requests, reviews, and other project spaces, including interactions where someone represents the project.

### Expected behavior

- Be respectful and patient. Help newcomers understand the project.
- Critique ideas and code with specific evidence; avoid personal attacks.
- Respect different backgrounds, identities, abilities, and opinions.
- Keep discussions relevant. Accept constructive feedback and correct mistakes.
- Protect privacy. Remove sensitive information from logs and examples.

Harassment, threats, discriminatory insults, sexualized conduct, doxxing, impersonation, spam, and repeated disruption are not allowed. Publishing someone's private information without permission is not allowed. Respectful technical disagreement is welcome.

### Reporting and moderation

Musa ([googIeuser](https://github.com/googIeuser)) maintains and moderates this project. To request maintainer attention, open an issue with a brief, non-sensitive description and links to relevant public project content. If details require privacy, ask for a private contact channel before sharing them. Do not publish personal information or private conversation screenshots.

For violations of GitHub's rules, use **Report content → Report abuse to GitHub Support**, following [GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Reports sent to GitHub Support go to GitHub, not directly to the maintainer. Vulnerabilities belong in the [private security channel](https://github.com/googIeuser/Claude-Pro-Dev/security/advisories/new), following [SECURITY.md](SECURITY.md).

The maintainer may request corrections, remove/hide content, close/lock discussions, or restrict participation. Responses should consider severity, impact, and repeated behavior; serious threats or harassment can lead to immediate restrictions. The rules apply to everyone, including the maintainer. Affected people may request reconsideration with relevant context through a non-sensitive issue or an agreed private channel.

Reports are shared only as needed for moderation. Public issues remain public; never use them for confidential details. No response deadline is promised. This policy does not replace GitHub's own reporting process.

## Türkçe

Claude Pro Dev, her geçmişten ve deneyim seviyesinden kişiye açıktır. Kurallar issue, pull request, kod incelemesi ve diğer proje alanlarında; projeyi temsilen yapılan etkileşimlerde geçerlidir.

### Beklenen davranış

- Saygılı ve sabırlı ol; yeni katılanlara yardımcı ol.
- Fikirleri ve kodu somut kanıtlarla eleştir; kişisel saldırı yapma.
- Farklı geçmişlere, kimliklere, yeteneklere ve görüşlere saygı göster.
- Konuyla ilgili kal; yapıcı geri bildirimi kabul et ve hatalarını düzelt.
- Gizliliği koru; kayıt ve örneklerden hassas bilgileri çıkar.

Taciz, tehdit, ayrımcı hakaret, cinsel içerikli rahatsız etme, özel bilgileri ifşa etme, kimliğe bürünme, spam ve tekrarlanan tartışma bozma davranışları yasaktır. Birinin özel bilgilerini izinsiz yayımlama. Teknik kararlara saygılı biçimde itiraz edebilirsin.

### Bildirim ve moderasyon

Projenin bakımını ve moderasyonunu Musa ([googIeuser](https://github.com/googIeuser)) yürütür. İnceleme istemek için kısa ve hassas bilgi içermeyen bir issue aç; ilgili herkese açık proje içeriğine bağlantı ver. Ayrıntılar özel kalmalıysa önce özel iletişim kanalı iste. Kişisel bilgileri veya özel konuşma görüntülerini yayımlama.

GitHub kurallarını ihlal eden içerikler için **Report content → Report abuse to GitHub Support** seçeneğini [resmî bildirim rehberine](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) göre kullan. GitHub Support kanalına gönderilen bildirimler bakım sorumlusuna değil GitHub'a gider. Güvenlik açıklarını [özel güvenlik bildiriminden](https://github.com/googIeuser/Claude-Pro-Dev/security/advisories/new), [SECURITY.md](SECURITY.md) yönergelerine göre ilet.

Bakım sorumlusu düzeltme isteyebilir, içerikleri kaldırabilir/gizleyebilir, tartışmaları kapatabilir/kilitleyebilir veya katılımı sınırlandırabilir. Kararlar ciddiyet, etki ve tekrar durumuna göre verilir; ağır tehdit veya taciz doğrudan kısıtlamaya yol açabilir. Kurallar bakım sorumlusu dahil herkes için geçerlidir. Karardan etkilenen kişi, hassas bilgi içermeyen bir issue veya üzerinde anlaşılmış özel kanal üzerinden ek bağlamla yeniden değerlendirme isteyebilir.

Bildirimler yalnızca moderasyon için gerektiği ölçüde paylaşılır. Herkese açık issue'lar gizli değildir; özel ayrıntıları burada paylaşma. Yanıt süresi taahhüt edilmez; bu politika GitHub'ın kendi bildirim sürecinin yerine geçmez.
