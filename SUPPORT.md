# Support / Destek

English and Turkish questions, reports, and contributions are welcome.

| What you need | Where to go |
| --- | --- |
| Install, update, choose models/effort, or fix a missing command | [English README](README.md#troubleshooting) / [Türkçe README](README.tr.md#sorun-giderme) |
| Ask a usage question | [Help form](https://github.com/googIeuser/Claude-Pro-Dev/issues/new?template=help.yml) |
| Report a reproducible defect | [Bug form](https://github.com/googIeuser/Claude-Pro-Dev/issues/new?template=bug_report.yml) |
| Suggest an improvement | [Feature form](https://github.com/googIeuser/Claude-Pro-Dev/issues/new?template=feature_request.yml) |
| Disclose a vulnerability | [Private security report](https://github.com/googIeuser/Claude-Pro-Dev/security/advisories/new), following [SECURITY.md](SECURITY.md) |
| Report harmful community behavior | [Code of conduct](CODE_OF_CONDUCT.md#reporting-and-moderation) |

Before reporting, check the README and [existing issues](https://github.com/googIeuser/Claude-Pro-Dev/issues). Include the Pro Dev, Claude Code, Windows, and PowerShell versions; the smallest reproduction; expected/actual behavior; and a short sanitized error excerpt. For model questions, distinguish the requested model/effort from what Claude Code actually reports. `unknown` does not mean zero usage.

Do not upload credentials, account files, complete transcripts, private code, or personal paths. A focused synthetic example is more useful than an unedited session dump. Support is provided as time permits, without a response deadline or account-limit change. Subscription billing and account-access problems belong to [Anthropic support](https://support.claude.com/).

## Türkçe

Türkçe ve İngilizce destek alabilir, hata veya öneri gönderebilirsin. Önce [sorun giderme bölümünü](README.tr.md#sorun-giderme) ve mevcut issue'ları kontrol et; ardından yukarıdaki uygun formu seç.

Pro Dev, Claude Code, Windows ve PowerShell sürümlerini; en küçük tekrar adımlarını; beklenen/gerçek davranışı ve temizlenmiş kısa hata çıktısını paylaş. Model konularında talep edilen ayar ile Claude Code'un bildirdiği modeli/eforu ayır. `unknown`, sıfır kullanım demek değildir.

Kimlik bilgisi, hesap dosyası, tam konuşma kaydı, özel kod veya kişisel dosya yolu paylaşma. Güvenlik açığını herkese açık issue'ya yazma; [özel kanalı](https://github.com/googIeuser/Claude-Pro-Dev/security/advisories/new) kullan. Destek, bakım sorumlusunun ayırabildiği zamanda sağlanır; yanıt süresi veya hesap limiti değişikliği taahhüt edilmez.
