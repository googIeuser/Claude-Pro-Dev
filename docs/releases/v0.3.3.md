# Claude Pro Dev 0.3.3

Fresh defaults: **Opus 5.5 main**, **Sonnet 5.5 executor**, **Opus 5.5 advisor**, all at **medium** effort. Select Haiku 5.5 or another supported model/effort through `/prodev-model`; use native `/model` and `/effort` for the main session.

Normal reinstall preserves personal model/effort choices. Run the downloaded installer with `-ResetModelDefaults` to explicitly apply the new main-model/effort profile to an existing setup. `/prodev-model reset` resets session role choices only.

Version-pinned role defaults, explicit overrides, inherited effort, installation upgrade, configuration preservation and rollback are covered by the [verification report](../VERIFICATION.md). Account/host restrictions still apply; no subscription savings claim is added.
