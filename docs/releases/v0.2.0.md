# Claude Pro Dev v0.2.0

This release makes behavior inspectable: hook and installation doctors, exit-code verification receipts, explicit project checks and session metrics without raw bodies. It fixes the live /prodev skill collision and stale-cache upgrades, adds PowerShell policy coverage, and gives failure context priority in long logs.

The package includes live CLI smoke tests and a reproducible A/B pilot. Read docs/VERIFICATION.md and docs/PILOT.md for actual evidence and limits. No subscription savings, comprehensive secret protection or complete project correctness guarantee is claimed.
