Claude Pro Dev 0.1.0 combines focused engineering instructions with native Mods helpers: usage/cache HUD, observed agent flow, manual queue and local next steps.

The standalone PowerShell installer embeds the plugin, checks configuration, retains backups and restores the prior package/settings on failure. It handles populated plugin lists and older same-name collisions.

Download install.ps1 or the source ZIP; SHA256SUMS.txt covers both. Requires Windows PowerShell 5.1+ and an existing Claude Code 2.1.287+ installation.

Starter release with best-effort guards. Filtering can omit evidence. Subscription savings and live UI usability have not yet been benchmarked. Automated tests do not use a model account.
