# Claude Pro Dev v0.3.1

Choose implementation/advisor models and reasoning effort without changing global settings.

```text
/prodev-model executor haiku low
/prodev-model advisor opus high
/prodev:advisor Fix the parser and run its tests.
```

`executor auto medium` lets the workflow request Haiku for narrow, clear assignments and Sonnet for complex work. Model aliases, explicit 5.5 IDs, inherited settings, and reset are supported. New choices affect future Pro Dev agents in the current session. The main model remains the coordinator; native `/model` and `/effort` control it.

Claude Code 2.1.293+ is required for Haiku 5.5. Thinking-off is not offered for 5.5 models. Host policy, account access, and capability limits can constrain/substitute requested values; verify actual values in `/tasks`. Auto mode is prompt guidance, not a guaranteed classifier or quota saving. Split-pane effort behavior depends on the host; use in-process teams for individual effort settings.

Native tests cover the model/effort boundaries with controlled external execution. Local command smoke starts no model requests. Live model quality and actual team coordination remain separate signed-in checks. [Verification](../VERIFICATION.md).
