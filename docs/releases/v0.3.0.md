# Claude Pro Dev v0.3.0

Subscription-first advisor and team workflows, with clearer English and Turkish documentation.

- `/prodev:advisor <task>` uses a Sonnet executor turn and focused read-only Opus guidance through Claude Code agents.
- `/prodev:team <task>` coordinates experimental native Agent Teams with separate assignments and file ownership.
- `install.ps1 -EnableAgentTeams` enables the native feature while preserving other environment settings and rollback.
- The Pro Dev command/file-name guard, `/prodev-guard`, and profile keyword screening are removed. Claude Code permissions still apply; output redaction remains.
- New metrics omit API billing estimates. Session report schema is 2 and no longer includes `counters.blocked`.

These workflows require available models and consume normal account allowance; no separate API key or service is required by the plugin. Experimental teams require an interactive session and restart after enabling. Static/native checks do not establish live model behavior or savings. See [verification scope](../VERIFICATION.md).
